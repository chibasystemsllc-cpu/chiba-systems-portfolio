# 千葉システムズ合同会社｜Portfolio

千葉システムズ合同会社の会社ポートフォリオサイトです。

## コンセプト
IT事業を本業とする一人法人が、新規事業として動画編集を開始した、という正直で信頼感のある構成です。
動画編集の経験が浅いことは隠さず、「実績を積み上げている段階」と表現しています。

## 公開前に変更する箇所
- `index.html` の `CONTACT_EMAIL` を実際の問い合わせ用メールアドレスに変更
- Company Profile の会社情報を必要に応じて更新
- Works の Sample Video を実際の制作サンプルに差し替え
- 必要に応じて会社ロゴ・画像・動画を追加

## 公開
S3の静的Webサイトとして配置できます。本番環境ではS3単体の公開より CloudFront + HTTPS 構成を推奨します。
